Data Storage / डेटा कहाँ सेव है?

This demo stores data in the browser's local storage on this device. It is not yet a shared online database, and it does not automatically sync between computers. Download backups regularly. For real production use, connect a secure server/database and server-side authentication.

यह डेमो डेटा इसी डिवाइस के ब्राउज़र में सेव करता है। अलग कंप्यूटर पर डेटा अपने-आप सिंक नहीं होगा। वास्तविक उपयोग से पहले सुरक्षित ऑनलाइन डेटाबेस और सर्वर-आधारित लॉगिन जोड़ना जरूरी है।
